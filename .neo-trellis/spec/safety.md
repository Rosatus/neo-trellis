# 安装与知识契约

2026-10-20 的实现约定，修改时必须保留或明确讨论改变：

1. 预览不写入项目。应用前备份被替换/删除的原件。
2. 不自动 Git commit，不扫描私人会话，不改用户级宿主信任配置。
3. 不跟随符号链接执行安装/迁移写入，不允许目标路径逃出项目。
4. 保留非受管理指令与配置；本地改过的受管理文件发生冲突时停止。
5. 不通过自动修改契约掩盖代码冲突；推断不能冒充已确认事实。
6. 父级范围知识不能被子级路由遮蔽。
7. 2026-10-21 用户确认：迁移默认在修改前完整压缩原始 .trellis，校验清单与哈希；写入成功、依赖检查通过且源未变后整体删除。归档失败或依赖未解决不得删除源；--keep-trellis 可保留完整原目录。

证据：安装、迁移、路由测试；设计依据为用户对通用 AGENTS 路由、外置地图和有证据知识的明确要求。
